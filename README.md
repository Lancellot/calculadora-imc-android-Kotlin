# Calculadora de IMC

## 📝 Descrição
O projeto **Calculadora de IMC** é um aplicativo Android moderno e intuitivo desenvolvido para ajudar no monitoramento da saúde. Ele calcula o Índice de Massa Corporal (IMC) com base no peso e altura inseridos pelo usuário, exibindo a categoria correspondente e fornecendo um feedback visual imediato.

## 🚀 Tecnologias Utilizadas
- **Linguagem:** [Kotlin](https://kotlinlang.org/)
- **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose)
- **Design System:** [Material 3](https://m3.material.io/)
- **Gerenciamento de Dependências:** Versão baseada em Version Catalog (libs.versions.toml)

## ✨ Funcionalidades
- **Cálculo Preciso:** Calcula o IMC utilizando a fórmula padrão (peso / altura²).
- **Interface Responsiva:** Design adaptável para diferentes tamanhos de tela.
- **Validação Inteligente:** Aceita tanto pontos quanto vírgulas como separadores decimais.
- **Feedback por Cores:** O resultado muda de cor conforme a categoria (Abaixo do peso, Peso normal, Sobrepeso, Obesidade).
- **Suporte a Rolagem:** Interface preparada para dispositivos com telas menores através de `verticalScroll`.

## 🛠️ Como Rodar o Projeto
1. Certifique-se de ter o **Android Studio** instalado (versão Ladybug ou mais recente recomendada).
2. Clone este repositório ou baixe o arquivo ZIP.
3. No Android Studio, vá em `File -> Open` e selecione a pasta do projeto.
4. Aguarde a sincronização do Gradle.
5. Conecte um dispositivo físico ou utilize um Emulador (API 24+).
6. Clique no botão **Run** (ícone de play verde).
